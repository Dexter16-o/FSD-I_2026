# FSD-I 2026

Lecture and practical programs for **Fundamentals of Software Development I (FSD-I)**. This repository collects the HTML, CSS, and related examples completed during college lectures.

## Repository structure

| Folder | Contents |
| --- | --- |
| `T1/Programs/` | Introductory HTML programs, practical work, and supporting media files. |
| `T2/CH4/` | Chapter 4 HTML and CSS examples, with supporting files. |
| `T2/CH5/` | Chapter 5 examples, including animation and previous-question practice. |
| `T3/CH_6/` | Chapter 6 programs grouped by lecture (`Lec_1_2`, `Lec_3_4`, and `Lec_5_6`), plus reference links. |

## How to view the programs

No setup is needed for the basic examples. Open a `.html` file in a web browser, or open the repository in a code editor and use its live preview/Live Server feature. Keep each example alongside its referenced images, audio, CSS, and other assets so those files can load correctly.

Some examples may load libraries such as Bootstrap from a CDN, which requires an internet connection.

## Note

These files are maintained as a personal collection of classwork and practice programs. File names and topics follow the lecture material and may not be arranged as a standalone application.
